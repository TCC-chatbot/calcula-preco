# Calcula Preço

Plataforma PWA para precificação de produtos e serviços.

## Projeto Integrador - SENAC

O projeto tem como objetivo auxiliar pequenos empreendedores a calcular preços de venda considerando custos, despesas, taxas e margem de lucro desejada.

## Funcionalidades previstas

- Precificação de produtos para revenda
- Precificação de produtos de fabricação própria
- Precificação de serviços
- Simulação de preços e margens
- Funcionamento offline

## Tecnologias

HTML, CSS e JavaScript.
